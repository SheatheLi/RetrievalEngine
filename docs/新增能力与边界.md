## 独立标签与分阶段质量归因

`src/evaluation_protocol.py`接受冻结查询、外部相关性标签、候选、排名与耗时，分别给出候选阶段Recall、最终Recall@K、nDCG@K、MRR@K，记录候选流失与排名流失的具体文档ID。比较函数要求查询集合及标签来源完全一致，以配对Query Bootstrap估计查询采样的不确定性。

`python -m src.evaluation_protocol examples/retrieval_queries.json --k 3`

**限制**：离线评估不能证明用户满意度、在线转化或真实服务端端到端延迟。标签必须与被评模型独立，否则评价具有循环性；Bootstrap默认查询独立同分布，不能在相关Session中无条件使用。
